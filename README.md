# Turuselli — versiones

Este repositorio solo contiene los **paquetes compilados** de Turuselli, publicados como *Releases*.
El código fuente está en un repositorio privado.

- Cada release `vX.Y.Z` trae `Turuselli-X.Y.Z.zip` y su huella `Turuselli-X.Y.Z.zip.sha256`.
- En la PC del salón, el acceso directo **ACTUALIZAR TURUSELLI** consulta el último release,
  verifica la huella e instala la versión nueva (con vuelta atrás automática si algo falla).
- Para instalar de cero: descomprimir el `.zip` y hacer doble clic en `INSTALAR.bat`.

Los paquetes no contienen datos de clientes ni contraseñas.
